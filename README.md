## LisaHost是什么，先搞清楚再下单

LisaHost（中文站内写作"丽萨主机"）是一家2017年成立、总部在香港新界的VPS/VDS服务商，主营产品线覆盖美国（洛杉矶、纽约、芝加哥、西雅图）、中国香港、中国台湾、日本、新加坡、英国、韩国、德国、越南等多个机房。它在国内跨境圈子里被提起最多的原因，不是价格便宜，而是"双ISP家宽住宅IP"和"原生IP"这两个卖点——简单说，就是这些IP在互联网上看起来像普通家庭用户在上网,而不是机房服务器IP，所以在做TikTok账号运营、海外社媒营销、流媒体解锁这类对IP属性敏感的业务时，被限流或者被标记的概率会明显低于普通数据中心IP。多篇第三方测评也提到，用LisaHost的美国双ISP住宅IP跑TikTok账号，数据表现相对稳定，没有频繁遇到因IP问题被限流的情况。

除了住宅IP系列，LisaHost也有走AS9929、AS4837精品网络和CN2 GIA线路的常规VPS，这类产品更偏向建站、远程办公、轻量应用这些对国内访问速度有要求、但不需要住宅IP属性的场景。所以购买前的第一步,其实是先想清楚自己要解决的是"IP属性问题"还是"线路速度问题"，这两类需求对应的产品完全不同。

## 购买前先分清三类产品，别选错方向

LisaHost官网的产品分组多达二十几个，乍一看容易挑花眼，但拆开看其实就三条主线。

第一类是**常规精品网络VPS**，走AS9929或AS4837线路，走的是普通机房IP或原生IP（非住宅属性），带宽和流量配置相对灵活，价格也最便宜，年付低至199元起。这类适合只是想要一台国内访问速度过得去的海外VPS，用来建站、跑脚本、做代理中转，对IP是不是"住宅属性"没有硬性要求的人。

第二类是**双ISP家宽住宅IP系列**，这是LisaHost真正的招牌产品，覆盖美国、中国香港（iCable、HGC）、日本、韩国、英国、德国、越南等地区。这类IP因为模拟真实家庭宽带用户，解锁流媒体本地内容、做TikTok/Instagram/Facebook账号运营、跨境电商店铺管理时相对不容易被平台判定为异常。代价是价格更高，同配置下通常比普通VPS贵出一倍甚至更多。

第三类是**住宅IP VDS（虚拟专用服务器）**，比如美国西雅图Atlas Networks、加州洛杉矶Astound Broadband、日本IIJ双ISP住宅这几个系列，主打"更真实的家庭网络托管"属性，价格更高，而且退款规则也不一样——这几款官网明确标注"特殊产品，退款仅退网站余额"，不适用于常规48小时无条件退款政策，购买前一定要留意这一点。

## 退款政策和几个容易踩坑的地方

LisaHost官网服务条款里写得很明确：**普通产品支持48小时内无条件退款**，但有几个例外——已经用掉超过5%流量或20GB流量（取较小值）的服务不算"没用过"，不给退；开通费、支付手续费这类费用本身不可退；如果账户被判定滥用（比如违反可接受使用政策），直接没有退款。48小时之后提出的退款申请，官网说法是"case by case"逐个判断，不是自动拒绝，但也不是保证能退。

另外要重复强调一次：**住宅IP VDS系列（洛杉矶、西雅图、日本、德国住宅IP这四款）退款只退网站余额，不退回原支付方式**，这一条和普通VPS的48小时无条件退款政策不是一回事，买之前一定要看清楚商品页面上有没有这行提示。

还有一个细节是IP更换政策：如果拿到的IP恰好在黑名单上，从服务开通起24小时内报备可以免费更换,超过这个时间窗口之后再申请换IP，会收取额外费用。这一条对做TikTok或者流媒体解锁的用户比较重要，拿到机器第一件事最好先测一下IP有没有被标记，别拖到第二天才发现问题。
